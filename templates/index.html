Project Overview

MedVision‑Pneumo is a web-based multi‑model deep learning framework for automated pneumonia screening from chest X‑ray images, designed as an explainable decision‑support tool.

  • Five CNN‑based models (custom architecture and transfer learning backbones).
  • On‑demand inference delivered through a Flask web interface.
  • Per‑prediction confidence scores with Grad‑CAM visual explanations.
Dataset

Kaggle – Chest X‑Ray Images (Pneumonia), by Paul Timothy Mooney. Used strictly for academic and research purposes.
